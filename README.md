# Prompt Lens · AI 提示词反提取

在线使用（GitHub Pages）：https://yujiajia1230.github.io/prompt-extractor/

给它一张照片、一段视频，或一条视频链接，它把画面反推成可以直接拿去生成的提示词。

## 它能做什么

- **照片反推**：上传一张图，输出可直接用于即梦 / 可灵 / 海螺等工具的中文提示词（附英文版）。
- **视频反推**：上传 MP4 / MOV，页面在浏览器本地自动均匀抽 6 帧（也可拖动进度条补抓任意一帧），多帧一起分析，保证全程内容的一致性——服装、配饰、道具逐项列全，运镜按时间顺序拆。
- **链接读取（实验性）**：粘贴抖音 / 小红书等链接，尝试读取封面信息。受浏览器跨域限制不一定成功；失败时下载视频再上传文件，效果完全一样。
- **结构化输出**：主题 / 中文提示词 / 英文提示词 / 拆解（主体·外貌妆造·服装配饰·场景·光线·镜头运镜·画风质感·时长节奏）/ 一致性要点 / 不确定项。看不清的地方标“推测”，不编造。

## 怎么用

1. 用浏览器打开 `index.html`（或 GitHub Pages 地址）。
2. 第二步填接口设置：任意 **OpenAI 兼容** 的接口地址（以 `/v1` 结尾）、一个**带视觉能力**的模型名、你的 API 密钥。
3. 第一步给内容 → 第三步点“开始反提取”。

## 隐私

- API 密钥只保存在你自己浏览器的 localStorage 里，页面代码不收集、不上传密钥到任何第三方服务器。
- 上传的照片和视频帧只在你本地浏览器里处理，抽帧完成后直接发给你自己填的那个接口。

## 已知限制

- 链接读取受平台防盗链与浏览器跨域策略影响，成功率不稳定，视频文件上传是最稳的路径。
- 反推质量取决于所选模型的视觉能力；帧数太少时视频后半段可能拆不准，可手动补抓关键帧。
